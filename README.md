# KSC Modern Website

A custom React + Vite concept website for Khamis Al Sharqah Contracting Co. (KSC).

## Run locally

1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:

```bash
npm install
npm run dev
```

4. Open the local URL shown by Vite.

## Build for Vercel

```bash
npm run build
```

The production build is created in `dist/`.

## Notes

- The KSC logo supplied for the design is in `public/images/ksc-logo.png`.
- Project imagery currently uses Unsplash URLs as temporary design placeholders.
- Replace placeholder phone/email/project content with KSC-approved information before production.
- Do not connect the production domain until the company has approved the final design and the existing site's DNS/email dependencies have been checked.
